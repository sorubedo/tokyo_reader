# Adwaita 视觉语言以设计规则为依据，而非主题包默认值

应用采用可明确辨认但不逐像素复刻 GNOME 桌面应用的 Adwaita 视觉语言，并由 Tokyo 主题变体提供配色。Adwaita 的组件模式与 HIG 是设计依据；`adwaita_gtk` 仅作为可复用的 `ThemeData` 底板，缺失的组件模式由应用补齐，当包的默认值与设计依据冲突时不以包为准。项目只实现自身页面实际使用的共享组件，不仿造完整的 libadwaita 组件库。视觉改造可以调整页面与组件结构，但须保留现有的导入、阅读、删除、主题选择和字体选择流程。界面采用桌面优先的响应式布局，并在约 360px 宽的窄窗口中通过重排或收起次要控件保持完整可用。Web 版 Header Bar 只承载真实的应用操作，不模拟操作系统窗口控制。
